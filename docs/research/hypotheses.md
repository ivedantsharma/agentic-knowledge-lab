# Hypotheses — Draft

We will refine these before experiments.

## H1
Agent-native hierarchical representations will improve performance on multi-hop questions relative to fixed-size flat chunking.

## H2
Hybrid retrieval will outperform lexical-only and dense-only retrieval on a mixed benchmark.

## H3
Adaptive retrieval will reduce unnecessary tool calls and context usage compared with a fixed retrieval policy.

## H4
Fine-tuning for retrieval actions may improve reliability, but its value must be measured against strong prompt-only baselines.

Important: we are allowed to disprove our own hypotheses. That is research.
