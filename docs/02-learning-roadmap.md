# Learning Roadmap

We learn only what is needed for the next engineering step.

## Phase 0 — Foundations and environment
Learn:
- Codespaces basics
- Terminal basics
- Git and GitHub basics
- Python environments
- repository structure
- basic LLM terminology
- documentation system

Deliverables:
- working cloud dev environment
- starter test passes
- CI passes
- documentation readable

## Phase 1 — Research framing
Learn:
- research questions
- hypotheses
- baselines
- metrics
- experimental design

## Phase 2 — Ingestion
Learn:
- parsing
- metadata
- chunking
- tokenization

## Phase 3 — Keyword retrieval
Learn:
- term frequency
- inverse document frequency
- BM25

## Phase 4 — Dense retrieval
Learn:
- embeddings
- cosine similarity
- nearest-neighbor search
- approximate nearest neighbors

## Phase 5 — Hybrid retrieval and reranking
Learn:
- rank fusion
- RRF
- cross-encoder reranking

## Phase 6 — Agentic search
Learn:
- agent loops
- tool calling
- state
- stopping conditions
- planning

## Phase 7 — Agent-native information architecture
Learn:
- hierarchies
- knowledge graphs
- claim/evidence graphs
- retrieval over structure

## Phase 8–9 — KnowledgeBench
Learn:
- benchmark design
- deterministic graders
- model graders
- adversarial task generation
- failure taxonomies

## Phase 10 — Fine-tuning
Learn:
- PyTorch basics
- Hugging Face Transformers
- LoRA / PEFT
- SFT

## Phase 11 — RL for retrieval policy
Learn:
- rewards
- trajectories
- policy optimization
- evaluation leakage risks

## Phase 12–14 — Research campaign
Learn:
- controlled experiments
- ablations
- confidence and variance
- failure analysis
- technical writing
